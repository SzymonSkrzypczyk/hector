## [Unreleased]

### Added
- Initial release of Hector CV generator.
- `generate` command to build PDF resumes from YAML data.
- `preview` command to view CVs in the browser with live reloading (`--watch`).
- `validate` command to ensure CV data matches theme requirements.
- `template` command to export raw theme YAML.
- Support for `normal` and `gray` themes.
- Documentation: `USER_GUIDE.md` and `DEVELOPMENT.md`.
