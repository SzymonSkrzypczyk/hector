## 📍 How to Contribute

### 1. ✍️ Fork and Clone

1. Fork the repository  
2. Clone your fork locally  
3. `git clone https://github.com/your-username/your-project.git`

---

### 2. 🧑‍💻 Set Up Your Environment

Make sure to install any prerequisites and configure your development environment.  
Refer to the **README.md** for environment setup and project structure. :contentReference[oaicite:4]{index=4}

---

### 3. 🐛 Report Bugs

If you find an issue:

1. Search existing issues to see if it’s already reported  
2. If not, create a **new issue** with:
- A clear title
- Steps to reproduce
- Expected vs. actual behavior
- Relevant screenshots or logs

This helps us understand and solve bugs faster. :contentReference[oaicite:5]{index=5}

---

### 4. 🛠 Submit Changes via Pull Request

1. Create a new branch for your work  
2. Make your changes  
3. Push to your fork  
4. Open a **Pull Request (PR)**  
5. Describe your changes clearly and link any related issues

We will review your PR and provide feedback. Expect respectful and constructive discussion. :contentReference[oaicite:6]{index=6}
